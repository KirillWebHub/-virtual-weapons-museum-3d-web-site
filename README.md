# Виртуальный музей

Учебная цифровая экспозиция по треку 03 «Безопасное обращение с оружием». Автор — Митичкин Кирилл Александрович.

Пять самостоятельных глав: винтовка Мосина, ППШ-41, СКС, пистолет Макарова и АКМ. В каждой — история, внешнее устройство, термины, культура безопасности, интерактивная 3D-иллюстрация и источники. Разнесение групп — художественная схема; оно не воспроизводит порядок реальной разборки.

## Запуск и сборка

Нужен Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Для готовой статической версии:

```sh
npm run build
npm run verify:site
npm run preview:pages
```

`dist/` содержит сайт. `verify:site` проверяет шесть страниц и все ресурсы в корне и подпапке репозитория, их контрольные суммы, MIME и настоящие ответы 404. Превью: `http://127.0.0.1:4185/-virtual-weapons-museum-3d-web-site/`. Это локальный адрес, доступный только на компьютере автора.

## GitHub Pages

В репозитории открыть **Settings → Pages → Source → GitHub Actions**. После push в основную ветку workflow собирает и проверяет сайт, публикует только `dist/`, затем проверяет публичные файлы и ревизию без авторизации. Ручной запуск доступен в Actions.

Ожидаемый адрес после успешного размещения: `https://KirillWebHub.github.io/-virtual-weapons-museum-3d-web-site/`. Готовность подтверждается успешным заданием `deploy`; наличие этой инструкции не означает, что сайт уже опубликован.

`version.json` на сайте содержит ревизию, время сборки и SHA-256 файлов. Проверка опубликованной версии:

```sh
node scripts/verify-site.mjs --url https://KirillWebHub.github.io/-virtual-weapons-museum-3d-web-site/ --revision COMMIT_SHA
```

`COMMIT_SHA` — полный идентификатор коммита успешной публикации. Команда не требует локальной сборки или аккаунта GitHub.

Авторы, источники и условия моделей указаны на сайте и в метаданных `history/`; уведомления библиотек, шрифтов и декоративной монеты находятся в `public/licenses/`. У сторонних ресурсов собственные лицензии. Монета используется без изменения оригинала, на условиях CC BY-NC-ND 4.0, в некоммерческой учебной работе.

В репозитории находятся исходники, активные модели, материалы и конфигурация сборки. Для просмотра преподавателю нужен только адрес опубликованного сайта; установка Node.js или вход в GitHub не требуется.
